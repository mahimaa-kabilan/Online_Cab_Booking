Our primary objective of Week 1 is to establish a clear technical foundation for the project before implementing the main application features.

The following objectives are planned:

1.Analyze the functional requirements and user roles.

2.Define the role-based access control structure.

3.Design the MySQL database schema and relationships.

4.Establish the project directory structure.

5.Set up the Node.js development environment.

6.Create the initial HTML, CSS, and JavaScript files.

7.Implement a basic HTTP server using Node.js built-in modules.

8.Plan the REST API endpoints required by the application.

9.Configure Git and GitHub for version control and progress tracking.
